# 講師向けスライド資料について

## ファイル一覧

| ファイル | 用途 | 時間 |
|----------|------|------|
| `WORKSHOP_TEMPLATE_180min.md` | 授業実施ガイド（詳細版） | 180分 |
| `INSTRUCTOR_SLIDES_180min.md` | 講師用スライド資料＆台本 | 180分 |
| `WORKSHOP_TEMPLATE.md` | 授業実施ガイド（基本版） | 90分 |

## INSTRUCTOR_SLIDES_180min.md の特徴

### 構成

**14スライド** で180分のワークショップを網羅：

1. **タイトル＆概要** （0-3分）
2. **到達目標** （3-6分）
3. **3つの言語の役割** （6-9分）
4. **方位磁石の基礎** （9-15分）
5. **67.5度の謎** （15-20分）
6. **実機での校正** （20-25分）
7. **テストと実機の違い** （25-30分）
8. **CI/CDパイプラインの見える化** （30-40分）
9. **意図的なバグ注入演習** （40-50分）
10. **100%カバレッジの落とし穴** （50-60分）
11. **応用題の紹介** （60-65分）
12. **学習成果の発表準備** （65-75分）
13. **クロージング＆振り返り** （75-80分）
14. **参考資料とフォローアップ** （80分以降）

### 各スライドの要素

- **スライドタイトル** （学習者向け投影内容）
- **ビジュアル表現** （図解、ダイアグラム、ASCII図）
- **講師スクリプト** （話す台本、全文表記）
- **タイムキープ指示** （推奨時間配分）
- **学習者への問いかけ** （対話・考える時間を確保）
- **期待される回答例**

### 使い方

#### オプション1：PowerPoint/Google Slides に変換して使用

```bash
# Markdown → PPTXに変換（pandoc使用）
pandoc INSTRUCTOR_SLIDES_180min.md -o INSTRUCTOR_SLIDES_180min.pptx
```

#### オプション2：Marp で自動スライド化

```bash
# Markdown → HTMLスライドに変換
# https://marp.app にアップロード、または
npm install -g @marp-team/marp-cli
marp INSTRUCTOR_SLIDES_180min.md --html --pdf
```

#### オプション3：そのまま講師の備忘録として使用

- テキストエディタで開く
- 各スライドの「講師スクリプト」を読み上げる
- ビジュアルは黒板またはホワイトボードに描く

### 講師スクリプトの特徴

- **全文で約3,500語** （180分を想定）
- **日本語 + 図解** で、非ネイティブ講師にも対応
- **学習者への問いかけ** を随所に配置（対話型学習）
- **各セクションの「意図」を明記** （なぜこの内容を学ぶのか）
- **よくある質問への答え例** を用意

### 学習目標の4柱（到達目標との対応）

| スライド | 対応する到達目標 | 学習内容 |
|----------|-----------------|---------|
| 2 | 全般 | 4つのキー概念を定義 |
| 4-5 | 目標1 | 8方位分類の数学 |
| 3 | 目標2 | 言語の包含関係 |
| 7-8 | 目標3 | テスト ≠ 実機 |
| 10 | 目標4 | テスト設計の限界 |

### 応用題の紹介（レベル別）

**スライド11** で以下の3段階を提示：

| レベル | 内容 | 難易度 | 時間 |
|--------|------|--------|------|
| 1 | 16方位コンパス | ⭐ 簡単 | 10-15分 |
| 2 | ナビゲーション計算 | ⭐⭐ 中 | 20-30分 |
| 3 | キャリブレーション表示 | ⭐⭐⭐ 高 | 30-45分 |

グループ/個人で選択可能。

### グループ発表ガイド（スライド12-13）

- 各グループ **5-7分** で発表
- **4つの観点** を話す：
  1. 3つの言語のうち、どれが好きか＆理由
  2. 応用題での実装内容
  3. テストで気づいたこと
  4. 次のプロジェクトへの応用

## トラブルシューティング

### Q: 時間が足りない

**A:** 以下をスキップ可能：
- スライド5（67.5度の詳細） → 図だけ見せる
- スライド9（バグ注入演習） → 講師が実演のみ（学習者は見学）
- 応用題3（難度高） → 応用題2まで

推奨短縮時間：**140分**

### Q: 時間が余った

**A:** 以下を拡張可能：
- スライド12（グループ発表） → 各グループ10分に延長
- 応用題 → 複数レベルに挑戦
- フリーディスカッション → CI/CD導入事例など
