# Changelog

## [0.1.0] - 2026-08-11

### Added
- Initial release
- MicrobotRecorder fluent API with method chaining
- MakeCodeBrowser for Playwright automation
- CursorRenderer for cursor visualization and click effects
- GifGenerator for GIF creation from image sequences
- Full test coverage for core components
- Example usage scripts
- Documentation and README

### Components
- `core/recorder.py`: Main API class
- `core/makecode_browser.py`: Browser automation
- `core/errors.py`: Custom exceptions
- `rendering/cursor_renderer.py`: Cursor drawing
- `rendering/gif_generator.py`: GIF generation

### Features
- Async/await support for browser automation
- 256-color GIF optimization
- Configurable frame rate (fps)
- Error handling with custom exception hierarchy
- Method chaining for intuitive operation sequences
